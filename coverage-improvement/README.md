# Coverage Improvement Workflow

A complete, drop-in package for systematic test coverage improvement using AI agents.

## 🎯 Purpose

This package provides a structured workflow for AI agents to:
1. Generate coverage reports
2. Identify coverage gaps
3. Write targeted tests
4. Track progress iteratively
5. Achieve comprehensive test coverage

## 📁 Package Structure

```
coverage-improvement/
├── README.md                    # This file - AI agent instructions
├── scripts/
│   ├── coverage.ps1            # Generate coverage reports (cargo tarpaulin)
│   ├── coverage_improvement_manager.ps1  # Manage improvement items
│   ├── coverage.json           # Coverage report (generated)
│   └── coverage_improvement.json  # Improvement items (generated)
├── docs/
│   ├── AI_AGENT_WORKFLOW.md    # Detailed AI agent instructions
│   ├── COVERAGE_ANALYSIS.md    # How to analyze coverage data
│   └── TEST_WRITING_GUIDE.md   # Best practices for writing tests
```

## 🚀 Quick Start for AI Agents

### Step 1: Generate Coverage Report
```powershell
cd coverage-improvement
.\scripts\coverage.ps1 -Loop
```

### Step 2: Review Improvement Items
The script will automatically:
- Generate coverage report
- Analyze gaps
- Show prioritized improvement items in `scripts/coverage_improvement.json`

### Step 3: Write Tests
Review `scripts/coverage_improvement.json` and write tests for:
1. **P1Critical** items first (large uncovered line regions)
2. **P2Important** items next (smaller gaps)
3. Focus on highest impact areas

### Step 4: Verify & Track
```powershell
# Run tests to verify coverage improvement
cargo test

# Mark completed items
.\scripts\coverage_improvement_manager.ps1 Complete 'ITEM_ID'

# Check progress
.\scripts\coverage_improvement_manager.ps1 Stats
```

### Step 5: Repeat Loop
Continue until coverage targets are met:
```powershell
.\scripts\coverage.ps1 -Loop
```

## 📊 Coverage Data Structure

### Coverage Report (`scripts/coverage.json`)
- Generated by `cargo tarpaulin` with JSON output
- Contains file-level and line-level coverage data
- Used to identify uncovered code regions

### Improvement Items (`scripts/coverage_improvement.json`)
Each item contains:
```json
{
  "id": "UNIQUE_ID",
  "title": "Test src/file.rs:Lines 10-25",
  "description": "Add tests for uncovered code...",
  "priority": "P1Critical|P2Important|P3Lower",
  "status": "Todo|Done",
  "category": "UnitTest",
  "created": "2026-05-12 09:07:14",
  "completed": null,
  "coverage_gap": {
    "coverage": 0,
    "file": "src/file.rs",
    "function": "Lines 10-25",
    "lines": [10, 11, 12]
  }
}
```

## 🎯 Priority Guidelines

- **P1Critical**: Large gaps (>10 consecutive uncovered lines)
- **P2Important**: Smaller gaps (≤10 consecutive uncovered lines)
- **P3Lower**: Manual items or low-priority areas

## 🔄 Continuous Improvement Loop

1. **Generate**: `.\scripts\coverage.ps1 -Loop`
2. **Analyze**: Review prioritized items
3. **Implement**: Write tests for high-priority gaps
4. **Verify**: Run tests and check coverage
5. **Track**: Mark completed items
6. **Repeat**: Continue until targets met

## 🛠️ Available Commands

### Coverage Script (`scripts/coverage.ps1`)
```powershell
.\scripts\coverage.ps1              # Basic coverage report
.\scripts\coverage.ps1 -Analyze    # Report + gap analysis
.\scripts\coverage.ps1 -Loop       # Complete workflow
```

### Improvement Manager (`scripts/coverage_improvement_manager.ps1`)
```powershell
.\scripts\coverage_improvement_manager.ps1                    # List all items
.\scripts\coverage_improvement_manager.ps1 Generate -CoverageFile scripts/coverage.json
.\scripts\coverage_improvement_manager.ps1 Complete 'ITEM_ID'
.\scripts\coverage_improvement_manager.ps1 Stats
.\scripts\coverage_improvement_manager.ps1 Add
```

## 📈 Success Metrics

- **Coverage Percentage**: Target >90%
- **P1Critical Items**: Should be 0 remaining
- **P2Important Items**: Minimize remaining items
- **Test Quality**: All tests pass, meaningful coverage

## 🚨 Important Notes

- Always run tests after writing new test code
- Focus on high-impact areas first (P1Critical)
- Update improvement items as work progresses
- Use the loop workflow for systematic improvement
- Document any special considerations or edge cases

## 🆘 Troubleshooting

If `cargo tarpaulin` fails:
```powershell
cargo install cargo-tarpaulin
```

If coverage data structure is unknown:
- Check the generated `scripts/coverage.json` format
- Update the parsing logic in `scripts/coverage_improvement_manager.ps1`
- Ensure you're using `cargo tarpaulin` (not llvm-cov)

If tests don't increase coverage:
- Verify tests actually execute the uncovered code
- Check test configuration and dependencies
- Review coverage report for actual execution paths
